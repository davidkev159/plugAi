02 — The Agent

How the research actually ran

Built with Composio's own SDK: a Claude-driven tool loop scoped to the COMPOSIO_SEARCH toolkit, run interactively rather than via a standalone API-key script — see the README for why, and for the exact code that would run it unattended.

What the agent did on its own

  • Called Composio's COMPOSIO_SEARCH_TAVILY_SEARCH (domain-restricted, includes raw page content) as the primary "read the docs" tool, with Google/DuckDuckGo search as fallback discovery.
  • Extracted auth method, access tier, API surface, MCP status, and a buildability verdict into a strict schema (Pydantic-validated), citing 2–3 real evidence URLs per app.
  • Self-flagged its own confidence and uncertainty per field — low-confidence apps are visible in the data table below, not hidden.
  • Recovered automatically from two direct-fetch failures (Zendesk 403, a guessed NotebookLM URL 404) by switching to search-based lookup instead of retrying the same broken path.

Where a human (or a second tool) had to step in

  • Caught a real conflation error — a search summary attributed the wrong auth method to Waterfall.io by blending it with an unrelated "Diligent Equity Waterfall API." Manually un-conflated using the individual source snippets.
  • Flagged a security red flag the agent found but shouldn't just repeat neutrally — a community Otter.ai MCP server that asks users to disable 2FA and hand over raw credentials.
  • Declared two honest dead ends — fanbasis and iPayX — rather than guessing, after multiple independent search attempts (including a domain-restricted one for iPayX) found nothing.
  • Ran an independent hand-verification pass (next section) using a second tool — direct WebFetch — against a stratified 20-app sample, and applied two precision fixes it surfaced.
03 — Verification

Accuracy is the point — so here's the proof

A stratified sample (2 apps per category, seeded random) was independently re-checked against the same primary sources using a different tool than pass 1 used: direct WebFetch instead of Composio's Tavily-search tool. Every result below is disclosed, hits and misses alike.

AppCategoryVerdictNote

Two precision fixes the cross-check surfaced

Datadog — pass 1 implied the Application key is needed on every call. WebFetch re-check showed it's only required for some endpoints, not universally. Fixed.
SE Ranking — pass 1 knew it was paid but not the numbers. WebFetch re-check surfaced exact pricing ($129/mo, $279/mo, $50 PAYG floor) and confirmed no permanent free tier. Sharpened.

The honest gaps

fanbasis & iPayX — no primary developer documentation could be located for either, despite multiple independent search attempts. Reported as "Blocked: unclear / needs human research," not guessed at.
NMI / Paygent Connect MCP claim — the WebFetch cross-check couldn't render the sidebar nav that Tavily's raw content had captured, so this one specific check came back inconclusive rather than confirmed. Disclosed as a tool limitation, not silently dropped.
